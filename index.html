价值叙事（优势 / 未包装价值 / PU 承接闸门）

先统一“为什么家长会买”，再进入动作执行；PU 先试点验证，不直接全量铺开。

我们已有优势

  • 价格带更有优势，家长试错成本低。
  • 排课和课消更灵活，决策门槛低。
  • 外教上课 + 中教答疑，双师服务承接更完整。

尚未被包装的价值

  • 家长核心关注是“25 分钟是否有效练习”。
  • 是否持续检查理解、是否引导更多开口。
  • 课堂不能只热闹，要有可见学习结果。
  • LingoAce 课程可帮助学生提升开口自信与表达准确性；围绕家长关心的“不敢说、说不准、进步看不见”三类问题，提供分层练习、纠错反馈与可视化学习结果。

PU 承接评估闸门

  • 准入：仅筛选高转化且低投诉 PH 老师。
  • 训练：课程亮点展现、语法解释、发音纠错、课堂控制、反馈脚本。
  • 试点：2-4 周小规模，达标再放量。
  • 达标：转化、投诉、家长反馈、执行质量四项同时看。

同纬度数据对比：点击数据点查看风险与原因

关键数据标签呈现：数据结果、原因、风险与管理判断。

转化抓手原则：销售建联是转化抓手，物料是信任放大器；家长必须看见学生开口状态与复述频次。

当前修正：视频开口次数监控存在偏差，建议改用“有效沟通时长 + 学生主动提问 + 课堂练习正确率”三指标并联。

课后表达：建议家长反馈采用“汉堡包表达法”：先肯定亮点，再说问题，最后给出解决路径与下一步计划。

课前 / 课中 / 课后 竞品 VS LingoACE对比：

竞品做法｜LingoACE 现状｜跨部门落地动作 + 关键指标；动作区按课件、老师、学生链路、课前提醒四维对齐。

执行主线：销售建联先解决家长问题，物料用于放大信任；每节课固定 2-3 标准互动案例，逐页沉淀授课亮点。
